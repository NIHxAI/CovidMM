# CovidMM
# COVID Multimodal Pipeline (Runner Guide)

This repository provides a Docker-based runner script (`covid_runner.sh`) to train/test the COVID severity prediction pipeline with flexible modality combinations.

## 1) Prerequisites

- Linux/macOS with `bash`
- Docker installed and running
- (Optional) NVIDIA GPU + NVIDIA Container Toolkit if you want GPU acceleration

---

## 2) Quick Start

From the project directory:

```bash
chmod +x covid_runner.sh
./covid_runner.sh --help
```

The runner will create these directories automatically:

- `logs/` : training/test logs
- `saved_models/` : model outputs and checkpoints

---

## 3) Configuration (Environment Variables)

You can override defaults via environment variables:

- `base` : project base directory (default: parent directory of the script)
- `IMAGE` : Docker image name (default: `noalcohol/covid:3env-offline`)
- `MODE_ENV` : runtime mode / conda env selector inside the container (default: `covid`)
- `RUN_ID` : fixed run identifier (default: autogenerated by the script, if implemented)

Example:

```bash
base=/base_dir \
IMAGE=noalcohol/covid:3env-offline \
MODE_ENV=covid \
./covid_runner.sh train ct ehr
```

---

## 4) Supported Modalities

You can pass any subset (any order) of:

- `ct`
- `cxr`
- `ehr`
- `scrna`

Examples:

- Single modality: `ct`
- Multi-modal: `ct ehr cxr`
- Another combo: `ehr scrna`

---

## 5) Usage

### 5.1 Train

```bash
./covid_runner.sh train <mods...> [-- extra train args]
```

Example:

```bash
./covid_runner.sh train ct ehr cxr
```

Pass extra arguments to the Python training entrypoint using `--`:

```bash
./covid_runner.sh train ct ehr -- --epochs 80 --batch-size 32 --lr 3e-5 --seed 777
```

### 5.2 Test

```bash
./covid_runner.sh test <mods...> [-- extra test args]
```

Example:

```bash
./covid_runner.sh test ct ehr
```

Reuse the same run id:

```bash
RUN_ID=20251112-183015 ./covid_runner.sh test ct ehr
```

### 5.3 Train then Test (All-in-one)

```bash
./covid_runner.sh all <mods...> [-- extra train args]
```

Example:

```bash
./covid_runner.sh all ct cxr scrna -- --epochs 60
```

### 5.4 Run All Modality Combinations

```bash
./covid_runner.sh combos
```

This trains (and/or tests depending on script implementation) all **non-empty** modality combinations.

---

## 6) Outputs

The runner organizes outputs by run id and modality tag.

- **Models / artifacts**
  - `saved_models/<RUN_ID>-<tag>/`

- **Logs**
  - `logs/<RUN_ID>-<tag>/train.log`
  - `logs/<RUN_ID>-<tag>/test.log`

`<tag>` is typically derived from your modality list, e.g.:
- `ct`
- `ehr`
- `ct-ehr`
- `ct-ehr-cxr`

---

## 7) Examples You Can Copy-Paste

Train only EHR:

```bash
./covid_runner.sh train ehr
```

Train CT + EHR with custom hyperparameters:

```bash
./covid_runner.sh train ct ehr -- --epochs 100 --batch-size 16 --lr 1e-4
```

Test CT + EHR:

```bash
./covid_runner.sh test ct ehr
```

Train then test CT + CXR:

```bash
./covid_runner.sh all ct cxr
```

## 8) Notes / Troubleshooting

- If Docker permission errors occur, ensure your user can run Docker without sudo or run with `sudo`.
- If using GPU, confirm the container can see the GPU:
  ```bash
  docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
  ```
- If you are running in an offline environment, make sure the Docker image already includes all required dependencies.
